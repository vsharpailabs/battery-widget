V-Sharp Battery Widget
======================

TO INSTALL
1. Make sure you have extracted this ZIP (right-click > Extract All).
2. Double-click "Install Battery Widget".
   If Windows shows "Windows protected your PC", click More info, then Run anyway.

The widget appears on your desktop. Right-click it for options.
You can delete this folder after installing.

TO UNINSTALL
Settings > Apps > Installed apps > Battery Widget > Uninstall.
This removes the widget, its shortcuts and its saved settings.
