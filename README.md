# V-Sharp Battery Widget

**Your laptop's battery, always in view.**
A small, free desktop widget for Windows that shows your battery level at a glance, so you're never caught out at 2%.

## ⬇ Download

**[Download the latest version](https://github.com/vsharpailabs/battery-widget/releases/latest/download/VSharpBatteryWidget-Setup.exe)**

Or see all versions on the [Releases page](https://github.com/vsharpailabs/battery-widget/releases).

## Features

- See your battery percentage at a glance
- Know when you're charging or running on battery
- Lightweight, runs quietly on your desktop
- Free, with no adverts and no sign-up

## Requirements

- Windows 10 or Windows 11
- A laptop or device with a battery

## Installing

1. Download `VSharpBatteryWidget-Setup.exe` from the link above.
2. Double-click the file to run the installer.
3. If Windows shows **"Windows protected your PC"**, click **More info**, check the publisher, then click **Run anyway**. This message is normal for new apps from small publishers.

## Uninstalling

Open **Settings → Apps → Installed apps**, find **V-Sharp Battery Widget** and choose **Uninstall**.
